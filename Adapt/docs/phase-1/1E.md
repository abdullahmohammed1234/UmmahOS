# 1. Objective

Phase 1D showed that ADAPT can produce different decisions for materially different learner evidence.

Phase 1E asks:

> Does the explicit evidence-driven ADAPT workflow make more appropriate adaptive decisions than a simpler tutoring baseline when both systems receive the same learner scenarios?

This is a test of **next instructional decision**, not explanation quality.

---

# 2. Hypothesis

**H1:** ADAPT will make more evidence-appropriate instructional decisions than the baseline because it explicitly represents learner evidence, learner state, uncertainty, and adaptation decisions.

**H0:** ADAPT does not demonstrate a meaningful advantage over the baseline on the predefined evaluation criteria.

Do not claim H1 is supported unless the executed results justify it.

Predefined strong-support pattern (frozen before execution):

1. ADAPT counterfactual differentiation rate ≥ 0.80
2. ADAPT misconception-response rate ≥ 0.80
3. ADAPT uncertainty-handling rate ≥ 0.80
4. ADAPT noise-stability rate ≥ 0.80
5. ADAPT decision-traceability rate ≥ 0.80
6. ADAPT shows a meaningful advantage on decision appropriateness **or** counterfactual differentiation (absolute difference ≥ 5 percentage points)

If some but not all hold: **PARTIALLY SUPPORTED**
If no advantage is demonstrated: **NOT SUPPORTED BY THIS BENCHMARK**

# 3. Systems

## BASELINE-001 (Phase 1E)

A simple deterministic if-then tutor implemented in `benchmarks/phase1e/baseline.py`.

It may inspect: current challenge, learner response, reasoning, confidence, and history.

It does **not** create `LearnerState`, `Evidence`, or run `StateUpdater` / `AdaptationEngine`.

Documented heuristics (frozen):

1. Ambiguous language → `PROBE_UNCERTAINTY`
2. Guess language → `GATHER_MORE_EVIDENCE`
3. Missing reasoning and confidence → `GATHER_MORE_EVIDENCE`
4. ≥3 misconception keyword hits → `REMEDIATE`
5. Incorrect + arithmetic language → `MAINTAIN_DIFFICULTY`
6. Isolated error after three corrects → `MAINTAIN_DIFFICULTY`
7. Sudden WWWCCC pattern → `MAINTAIN_DIFFICULTY`
8. Two consecutive incorrects after earlier success → `DECREASE_DIFFICULTY`
9. Incorrect that contradicts mostly-correct history → `GATHER_MORE_EVIDENCE`
10. Correct + weak reasoning → `MAINTAIN_DIFFICULTY`
11. Correct + strong cues + high confidence + ≥2 prior corrects → `INCREASE_DIFFICULTY`
12. Else correct → `INCREASE_DIFFICULTY`; else incorrect → `DECREASE_DIFFICULTY`

Phase 1D's `BaselineTutor` remains a correctness-only helper for Phase 1D tests. It is **not** the Phase 1E comparison system. Using it here would cripple the baseline. That discrepancy is intentional and documented.

## ADAPT-001

The Phase 1D `AdaptPipeline`. History is replayed from `initial_learner_state` so ADAPT does not receive a privileged pre-built state.

# 4. Benchmark design

Both systems receive the same:

- scenario identity (not expected labels)
- current challenge
- current learner response

# 6. Expected behavior definitions

Canonical vocabulary:

```text
INCREASE_DIFFICULTY
MAINTAIN_DIFFICULTY
DECREASE_DIFFICULTY
REMEDIATE
PROBE_UNCERTAINTY
CHANGE_REPRESENTATION
GATHER_MORE_EVIDENCE
```

A decision is **appropriate** if it is in the scenario's acceptable set, not in the forbidden set, does not violate `forbid_next_difficulty`, and (for ADAPT on S-004) does not label the error `CONCEPTUAL`.

# 7. Metrics

Primary: M-001 appropriateness, M-002 counterfactual differentiation, M-003 evidence sensitivity, M-004 misconception response, M-005 uncertainty handling, M-006 noise stability, M-007 difficulty appropriateness, M-008 traceability.

Secondary: false mastery, false weakness, overreaction, underreaction, uncertainty overconfidence, misconception persistence.

Traceability requires evidence used, reason, confidence, and learner state. The baseline is not given a synthetic ADAPT trace.

---

# 8. Statistical rules

- Report numerator / denominator / rate
- Wilson 95% CI for primary binary metrics
- Percentage-point difference and relative improvement (relative omitted if baseline rate is 0)
- McNemar on paired appropriateness
- No significance claim from a percentage difference alone
- Deterministic; seed `20260813` recorded even though scenario generation is not randomized

# 12. Counterfactual results

ADAPT differentiated all 9 pairs:

| Pair | Dimension | ADAPT A | ADAPT B |
| --- | --- | --- | --- |
| CF-P1 | reasoning_quality | INCREASE_DIFFICULTY | PROBE_UNCERTAINTY |
| CF-P2 | misconception | INCREASE_DIFFICULTY | REMEDIATE |
| CF-P3 | learner_confidence | INCREASE_DIFFICULTY | MAINTAIN_DIFFICULTY |

Baseline differentiated CF-P1 and CF-P2, but **not** CF-P3 (both learners `INCREASE_DIFFICULTY`). That is the main adaptive gap: the simple tutor does not treat stated confidence as decision-changing when reasoning is otherwise strong.

# 13. Failures

## ADAPT

None on the frozen suite.

## Baseline (final run)

Three failures, all CF-P3-B: low-confidence learner still received `INCREASE_DIFFICULTY`.

## Execution history (not hidden)

**Run 1:** Baseline appropriateness 39 / 51. Twelve failures were `REMEDIATE` on correct algebra because the misconception regex matched `2x + 3` inside legitimate equations such as `2x + 3 = 11`.

**Cause:** baseline bug (over-broad keyword), not an ADAPT bug and not a label problem.

**Fix:** misconception heuristic restricted to explicit distribute-failure language (`didn't distribute` / `did not distribute`). ADAPT core, scenario labels, and metrics were not changed.

**Run 2 (final):** Baseline 48 / 51. Remaining failures are the intended CF-P3 confidence insensitivity.

---

# 14. Limitations

- Keyword/heuristic analysis, not an LLM and not a human study.
- One concept and a small challenge bank.
- CF-P2 cannot match raw accuracy exactly (misconception evidence is incorrect diagnostic answers).
- Perfect ADAPT scores reflect contract-aligned scenarios.
- Family-level Wilson intervals are wide (n=3).
- McNemar p=0.248 on appropriateness: do not claim confirmatory significance.
- Traceability is structurally guaranteed for ADAPT and structurally absent for the baseline; that metric is architectural, not empirical skill.

---

# 15. Conclusion

**Hypothesis: SUPPORTED** by the predefined strong-support pattern.

Caveats: the appropriateness advantage is small and not McNemar-significant. The clearer advantages are counterfactual differentiation (especially confidence) and decision traceability. On several required families the fair baseline is already appropriate.
