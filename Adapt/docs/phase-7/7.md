## 1. Objective

Phase 7 converts ADAPT from a technically validated prototype into a learner-facing product:

```text
Choose what to learn
       ↓
Answer naturally
       ↓
ADAPT observes
       ↓
ADAPT understands
       ↓
ADAPT changes strategy
       ↓
A different challenge appears
       ↓
Learner understands why
       ↓
Progress becomes visible
```

The core promise is unchanged:

> ADAPT adapts to how you learn, not just whether you are right.

That is a statement about challenge selection, not a claim that ADAPT improves learning.

## 2. Preservation

Frozen and unmodified:

- EvidenceAnalyzer
- StateUpdater
- AdaptiveStrategyEngine
- AdaptationEngine
- AdaptiveTutor (default bank and selector)
- Phase 1E–6 benchmarks, scenarios, and historical result files

New layers sit around the engine:

```text
Learner → AdaptiveTutor → Learner State + Strategy
                              ↓
                     Phase 7 Challenge Selector
                              ↓
                     Challenge Memory + Diversity Filter
                              ↓
                          Next Challenge
```

Algebra and Fractions sessions still use the Phase 3 `AdaptiveTutor` bank and selector so Phase 4–6 product behavior is unchanged. New domains use a catalog-backed tutor injected only for those sessions.

## 3. Content

Domain-neutral catalog under `src/adapt/content/`.

| Domain | Topics (examples) |
| --- | --- |
| Mathematics | Arithmetic, Algebra, Fractions, Geometry, Trigonometry |
| Calculus | Limits, Derivatives, Integrals, Optimization, Related Rates |
| Computer Science | Programming, Data Structures, Algorithms, OOP, Databases |
| Physics | Mechanics, Forces, Energy, Momentum, Electricity, Waves |
| Chemistry | Atomic Structure, Bonding, Stoichiometry, Acids, Reactions |
| Space | Solar System, Stars, Galaxies, Black Holes, Orbits, Cosmology |
| Quantum | Qubits, Gates, Entanglement, Algorithms |

Algebra and Fractions wrap the frozen Phase 3 bank. Calculus/trigonometry are subjects or nested topics (`calc-limits`, `math-trigonometry`), so historical `topic_id="calculus"` / `"trigonometry"` remain invalid.

Challenge types include DIRECT, MULTIPLE_CHOICE, ERROR_ANALYSIS, PREDICTION, APPLICATION, TRANSFER, DIAGNOSTIC, REMEDIATION, plus Quantum CONCEPT_CHECK, TRUE_FALSE, EXPLANATION, COMPARE, SCENARIO, SEQUENCE.

Difficulty is 1–5 in the catalog and mapped onto the frozen EASY/MEDIUM/HARD engine scale. Strategy is not equated with “difficulty + 1”.

Quantum misconception tags Q-M001–Q-M008 are evidence cues, not hardcoded strategy overrides.

## 4. Selection

`Phase7ChallengeSelector` ranks catalog items from:

1. Strategy compatibility  
2. Concept relevance  
3. Difficulty fit  
4. Evidence / diagnostic value  
5. Diversity  
6. Repetition avoidance  
7. Progression  

It never updates mastery or strategy. The same challenge (and challenge family) is avoided in a short window unless strategy is REMEDIATE.

## 5. Learner experience

Landing: “Learn differently with ADAPT.”  
Subjects → topics (mastery only when recorded) → challenge → lightweight evidence → feedback → What ADAPT noticed → Why this question? → next challenge → summary / progress / insights / journey.

Evidence defaults to answer + confidence + optional “How did you get this?”. Written explanation is optional unless the current plan needs more signal.

Research mode still shows Evidence → State → Strategy → Next Challenge from the actual `StepTrace`.

Counterfactual remains two live `AdaptiveTutor` runs from the same start.
