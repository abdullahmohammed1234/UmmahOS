## 1. Objective

Phase 1 established that ADAPT can analyze learner evidence and update learner state.

Phase 2 established that ADAPT can distinguish learner state from instructional strategy and change strategy based on evidence.

Phase 3 tests whether those capabilities work together as a continuous adaptive tutoring loop.

The system must demonstrate:

```text
Challenge
   ↓
Learner Response
   ↓
Evidence Analysis
   ↓
Learner State Update
   ↓
Strategy Update
   ↓
Strategy Decision
   ↓
Challenge Selection
   ↓
Next Challenge
   ↓
Learner Response
   ↺
```

This phase tests the integrated loop, not isolated functions.

---

## 2. Research Question

When a learner interacts with ADAPT over multiple steps, does learner evidence continuously influence learner state, instructional strategy, and subsequent challenge selection?

## 5. Session Model

`TutorSession` tracks:

- `session_id`, `learner_id`, `concept_id`
- `current_challenge`
- `learner_state`
- `strategy_state`
- `history`, `recent_evidence`, `used_challenge_ids`
- `step_number`
- `traces`
- `seed`

Initialization does not assume mastery:

- `mastery_estimate = 0.5`, `confidence = 0.2`
- `uncertainty = INSUFFICIENT_EVIDENCE`
- `strategy = ASSESS`

Sessions are isolated. `snapshot()` / `restore(snapshot)` preserve full-precision learner and strategy state. The same initial state, bank, responses, and seed reproduce the same trajectory.

## 7. Challenge Selection

`AdaptiveChallengeSelector` consumes the strategy decision. It does not pick difficulty independently of strategy.

| Strategy | Preference |
| --- | --- |
| INCREASE | higher difficulty, increased-difficulty / transfer / practice |
| DECREASE | lower difficulty, same concept |
| PROBE | diagnostic / probe, high `diagnostic_value` |
| REMEDIATE | targeted misconception remediation |
| MAINTAIN | similar difficulty, variation |
| GATHER_EVIDENCE / ASSESS | high-information, not increased difficulty |

Constraints: avoid immediate repetition; shift difficulty by one level; probe does not select `INCREASED_DIFFICULTY`; empty banks fail safe to `UNAVAILABLE`.

Challenge metadata added only where needed: `diagnostic_value`, `strategy_compatibility`. Types: `STANDARD`, `DIAGNOSTIC`, `PROBE`, `REMEDIATION`, `TRANSFER`, `INCREASED_DIFFICULTY` (existing `PRACTICE` retained).

## 14. Failures

No scored Phase 3 scenario failed the frozen appropriateness check on the persisted run.

Documented behavioral mismatches versus the *illustrative* longitudinal cartoon (not scored failures):

1. **T-001** first decision is `GATHER_EVIDENCE`, not the label `ASSESS`. `ASSESS` is the pre-response session strategy.
2. **T-002** reaches `REMEDIATE` via `DECREASE` rather than `PROBE` first.
3. **P3-CF-002B** is `GATHER_EVIDENCE` rather than `PROBE`. It is still not `DECREASE`.
4. **T-H-002** ends in `REMEDIATE` because incorrect answers that equal known misconception strings (e.g. `2/5`) are analyzed as misconception evidence.

Small-n 100% rates (n=3, n=5, n=7, n=8) are not precision claims; Wilson intervals are wide.

## 15. Limitations

- Evidence analysis is still keyword/heuristic. Strategy and selection quality cannot exceed evidence quality.
- `diagnostic_value` is a deterministic heuristic, not Bayesian information-gain optimization.
- Recovery and hysteresis thresholds are inherited from Phase 2; they were not retuned on the holdout set.
- Challenge-bank exhaustion eventually repeats items; immediate repeats are avoided first.
- Wrong answers that coincide with misconception cue strings are treated as misconception evidence even when the learner said they guessed.
- No LLM was introduced.

---

## 16. Conclusion

ADAPT is no longer only a collection of independently working components. Over multi-step sessions, learner evidence changes what the system believes, which strategy it chooses, and which challenge it presents next. That causal chain is fully traced.

The strongest evidence is counterfactual:

- Same start + strong evidence → higher mastery, `INCREASE`, harder follow-up
- Same start + weak evidence → near-prior mastery, `PROBE`
- Same start + delayed misconception → gather/probe, not global `DECREASE`
- Same remediation start + failures vs quality successes → stay in `REMEDIATE` vs leave remediation

Hypothesis for this phase: **supported** on the dedicated counterfactuals, longitudinal traces, and the Phase 3 suite, without claiming a valid percentage comparison against Phase 1F or Phase 2 (different tasks).
